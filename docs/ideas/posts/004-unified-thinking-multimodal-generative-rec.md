# Thinking 与混合模态推荐：研究设想

本页是研究方向，当前仓库尚无完整的多模态生成推荐、显式 Thinking 或 latent reasoning 训练与部署闭环。已有 PCVR 模型仍按概率预测契约执行。

## 参考线索

- 统一理解/生成：[SenseNova-U1](https://github.com/OpenSenseNova/SenseNova-U1)。
- 离散生成召回：[TIGER](https://arxiv.org/abs/2305.05065)。
- 标识泛化：[Better Generalization with Semantic IDs](https://arxiv.org/abs/2306.08121)。
- 业务任务：[TAAC 2025 全模态生成式推荐](https://arxiv.org/abs/2604.04976)。

这些工作提供不同任务的研究入口，不合并成一个已验证方法。模型规模、原始模态、数据授权、训练配方和评测各有边界。

## 两个需要分开验证的假设

**内容信息假设：** 文本/图像表示可能缓解低频和新物品的协同不足。前提是实际存在可用内容输入，且特征只使用预测时可见信息。

**额外计算假设：** 中间推理或潜变量计算可能改善复杂兴趣匹配，但也增加延迟、训练难度和泄漏风险。更长计算本身不证明更好推理，更不能用不可观察的思维描述充当机制证据。

## 分阶段原型

| 阶段 | 最小实现 | 验收 |
| --- | --- | --- |
| 内容分支 | 固定内容 embedding 与现有模型融合 | 新/低频物品分桶改善，成本可控 |
| 统一 token | 记录类型、缺失和时间合法性 | 与同预算双分支对照 |
| 离散标识 | codebook/映射及候选约束 | 覆盖、碰撞、合法候选与检索质量 |
| 额外推理计算 | 明确状态、目标与终止 | 等延迟/等成本比较及可复现消融 |
| 完整输出 | 接上目标任务实际评测 | 数据到输出真实闭环 |

先做最小可运行原型，不同时堆叠多模态、Semantic ID、强化学习和复杂 reasoning loss。每增加一个模块，先说明它如何在现有输入、训练目标与提交格式中发挥作用。

## 当前框架的可复用部分

配置、schema 边界、模型契约、训练器、checkpoint 和打包可以作为基础；新输入或输出契约变化必须原子更新生产者与消费者。不能把当前 `predictions.json` 当作生成召回候选列表。

研究材料见[论文索引](../../papers/index.md)，任务迁移边界见[2025 笔记](002-taac2025-competition-paper.md)。只有原型、质量与部署分别通过验收，才能提高对应成熟度声明。
