# TAAC 2025：全模态生成式推荐

原文：[Tencent Advertising Algorithm Challenge 2025: All-Modality Generative Recommendation，arXiv:2604.04976](https://arxiv.org/abs/2604.04976)。这是 2025 任务与数据的论文，不是当前 2026 PCVR 排序任务的运行说明。

## 任务是什么

论文介绍以用户历史预测下一物品的生成式推荐挑战，输入结合协同标识、行为与预计算多模态表示。TencentGR-1M/10M 为相关工业数据集，评估围绕候选召回的 HR/NDCG，与点式概率预测不同。

![赛事工作流，来源为论文归档图](img/taac2025/main-figure-1.png)

## 从方法中学什么

官方 baseline 将序列编码、对比训练与候选检索连接；高分方案探索行为条件化、Semantic ID、负样本与规模化。这些模块的价值依赖候选池、数据可用性与评估协议，不只是替换 Transformer 主干。

## 与当前工作区的区别

| 维度 | 2025 论文任务 | 当前框架 |
| --- | --- | --- |
| 输出 | 候选物品列表或召回结果 | user id 到二分类概率 |
| 主要指标 | HR/NDCG 等检索指标 | AUC、logloss 等分类指标 |
| 流程 | 表示学习、候选索引、检索 | 训练、评估、推理与提交文件 |

当前仓库没有由这篇笔记自动获得 Semantic ID、ANN 索引或完整生成召回流水线。迁移前先确认多模态字段是否真的存在，不能从 2025 数据推断 2026 输入。
